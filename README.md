### 📱 苹果手机（iPhone）全屏最佳体验步骤
1. 用 iPhone 自带的 **Safari 浏览器**打开上面的游戏链接（微信内点开请点右上角 `···` → **在默认浏览器中打开**）。
2. 点击底部中间的 **【分享图标 ⬆️】** → 选择 **【添加到主屏幕】** → 点 **【添加】**。
3. 桌面上会出现独立的 **「小丑牌」** 图标，点开即可 **100% 无地址栏全屏横屏游玩**，存档自动保存在手机本地。
4. 记得关闭手机左侧的静音拨片（或戴耳机）即可享受 7/4 拍迷幻配乐与筹码连击音效！
